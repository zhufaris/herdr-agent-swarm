Herdr Agent Swarm · Runtime Architecture

Durable, human-controlled coordination across Lark, SQLite, Herdr/TraeX, and user systemd.

● Authority boundaries

  • Herdr owns pane, terminal, session, and agent state.
  • SQLite owns workflow lifecycle, prompt FIFO, delivery intent, audit, and lease.
  • Lark owns only what a person sees; card text never repairs state.

● Durable state first

  • Multi-row workflow changes share one SQLite transaction.
  • Outbox retry can redeliver a CardKit operation but cannot re-run TraeX.
  • Dead letters preserve delivery evidence for operator recovery.

● Convergence, not event sourcing

  • Herdr socket events are bounded latency hints.
  • Session reconciliation reads a fresh authoritative snapshot.
  • Transcript ownership uses exact turn and start-time fences.
