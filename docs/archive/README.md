# Historical Documentation

This directory preserves completed and superseded engineering records. It is
evidence of earlier decisions and implementation work, not the authority for
current behavior. Start from the [maintainer documentation map](../README.md) for
current guidance.

## Contents

- `superpowers/` contains completed specifications, plans, audits, and tickets.
- `designs/` contains older standalone designs that predate or supplement the
  current architecture guides.
- `operations/` contains completed operational and performance audits.
- `architecture-artifacts/` contains superseded diagrams and visual-validation
  output retained for provenance.

Historical documents can contain old names, paths, commands, or implementation
assumptions. Revalidate any useful idea against current source, tests, and the
current architecture guide before applying it.
