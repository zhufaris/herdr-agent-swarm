# Active Engineering Records

This directory contains only engineering work that is still being designed or
implemented. There are currently no active records.

Completed and superseded designs, implementation plans, tickets, and audits are
retained under the [historical Superpowers archive](../archive/superpowers/).
They are engineering evidence, not current behavioral authority.

Current maintainer, user, and operator documentation starts at the
[maintainer documentation map](../README.md). New work should be added here only
while it is active and moved to the archive after implementation and validation
finish.
